# Password Reset Procedure

This procedure explains how to reset a sample Support Portal password.

## Audience

Portal users and service desk analysts.

## Prerequisites

- Access to the registered email account.

## Procedure

1. Open the sign-in page.

1. Select **Forgot password**.

1. Follow the instructions in the reset email.

1. Return to the sign-in page and test the new password.

## Expected result

The user can authenticate with the new password.

## Troubleshooting

If the email is not received, check spam and confirm the registered email address.
