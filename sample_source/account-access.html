Account Access Troubleshooting

Use this article when a user cannot sign in to the sample Support Portal.

Audience

Service desk analysts and portal users.

Prerequisites

  • The user has an active account.
  • The user can access their registered email address.

Procedure

  1. Confirm that the username is correct.
  2. Use the password reset procedure if the password is rejected.
  3. Check whether the account is locked before escalating.

Expected result

The user can sign in, or the issue is ready for escalation with the checks recorded.

Troubleshooting

If the reset email does not arrive, check spam and verify the registered email address.
